# Estudos de SQL & Banco de Dados

Este repositório foi criado para documentar e organizar meu aprendizado prático sobre **Banco de Dados Relacionais e Linguagem SQL**, focando na construção de fundamentos sólidos para o desenvolvimento Backend Java.

---

## Tecnologias e Ferramentas Utilizadas

- **SGBD:** MySQL
- **Gerenciador de Banco:** DBeaver
- **Editor de Código:** VS Code, Interface do DBeaver

---

## Conteúdos Praticados

Os scripts estão organizados para cobrir as principais operações de um banco relacional:

- [x] **Criação e Estruturação (DDL):** `CREATE DATABASE`, `CREATE TABLE`, definições de Chave Primária (`PRIMARY KEY`) e tipos de dados.
- [x] **Manipulação de Dados (DML):** `INSERT`, `UPDATE`, `DELETE`.
- [x] **Consultas (DQL):** `SELECT`, filtros com `WHERE`, ordenação com `ORDER BY`.
